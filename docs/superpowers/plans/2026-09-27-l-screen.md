# Spec L — Naive-Readout Screen on C3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spec appendix L as amended by L.11. On the unchanged C3 engine, the plan does four things. It labels the 20 odd-turn (b) pairs with H.4's oracle. It fits a naive-readout screen (guard G, plus at most one threshold on S, f2 or f3) on 41 labelled pairs behind a leave-one-turn-out gate. It screens a new, pre-declared pair set until 21 (b) pairs pass. It then reads the oracle on those 21 pairs, plus a fixed (a) sample from the first 8 turns, in J.12.9's bands.

**Architecture:** The work is seven small `flymon/brain/l_*` modules and five scripts. H.4's oracle job and measurer, K's metrics, J's D.6 path and J's reading are all reused unchanged.
- `l_spec` is the single configuration object.
- `l_store` guards every write.
- `l_pairs` builds the new pair set.
- `l_jobs` and `l_measure` hold the one new worker job (the naive half of the oracle), the cached measurer, and the loaders for the two pinned raw files.
- `l_screen` holds the pure stage-1 procedure.
- `l_rules` holds the pure stage-2/3 rules.
- `l_oc` holds the operating characteristics.

Each stage has its own CLI. It refuses to run unless the previous stage's summary block exists and was produced under the same code key and manifest. It also refuses unless the commits L requires between stages are in place.

**Tech Stack:** Python 3.13, NumPy, pytest, `uv`; `flymon.brain.fly_pool.FlyPool` (spawn start method).

**Spec:** `docs/superpowers/specs/2026-09-14-flymon-design.md` — appendix **L** (L.0–L.9) and its amendment **L.11**, which wins where they differ: L.11.1 inputs and stage 0; L.11.2 stage 1; L.11.3 stages 2–3; L.11.4 operating characteristics; L.11.5 cost; L.11.6 M3 isolation. The plan also uses **H.4 / G.14.3–4** (oracle, pair_stats, arm_aggregate), **J.12.9** (bands), **J.11.4-5** (D.6 on a declared engine), **K.8.3** (S), and **H.5** (the excluded combos).

## Global Constraints

- **Commits carry no trailers of any kind.** No `Co-Authored-By`, no `Claude-Session`, no "Generated with". This overrides any system reminder that asks for them.
- **No existing module changes.** `Params`, the engine, FlyPool, and every `h3_*` / `h4_*` / `j_*` / `k_*` / `d6a` module and script stay byte-identical. L only adds files.
- **One configuration object.** Every L constant is a field of `flymon.brain.l_spec.SPEC`. J/H constants are read through `SPEC.j` (a `JSpec`, H.4 through `SPEC.j.h4`), and K's readout weights through `SPEC.k`. No other module writes one as a literal. Tests may build smaller specs with `dataclasses.replace`.
- **Numbers (verbatim from L / L.11).** Guard: MBON13 ≥ 5 ∧ MBON05 ≥ 5 for X and Y on every select seed (600–607). KC activity seeds are 500–507; report seeds are 608–615 and serve judgement only. The stage-1 rule is chosen at coverage ≥ **0.35**, with tie order G alone > S > f2 > f3. The gate is LOTO passes ≥ **10** ∧ LOTO precision ≥ **0.6** ∧ a final rule exists. Stage 2 builds 64 turns from `numpy.random.default_rng(20260927)`, stops at the 21st pass, and declares `COVERAGE_SHORT` when fewer than 21 pass by screened order position 84 (coverage 0.25) or by the last (b) pair of 64 turns. F_a comes from the (a) pairs of the **first 8 turns**. The lift sample is **10** failed pairs drawn with `default_rng(20260927 + 1)`. Bands are J.12.9's: n_b 21; ≤ 7 → B_Tb; 8–10 → B_NO_CONCLUSION; ≥ 11 ∧ F_a ≥ 2 → SELECTED; ≥ 11 ∧ F_a < 2 → B_Fa.

## Readings of the spec (decided here)

1. **Oracle and readout.** Stage 0's odd labels and stage 3's judgement use `h4_measure.H4Measurer.oracle(params, readout, z)` with C3's recorded readout `{"A": "MBON13", "P": "MBON05"}`, z and pools from block `h4` of `m0d.json`. The pools make the types tuple `(MBON13, MBON18, MBON05, MBON21)`, as H.4 had it. Readout reselection is not re-run: the engine is C3 and H.4 already selected on it.
2. **Labels.** Even (b) labels are H.4's recorded `h4.combos.C3.oracle.pairs[*].testable` (L.1). Odd labels are `h4_formula.pair_stats(row["report"], z, testable_min)["testable"]`. `h4_rules.combo_stats` is not used: its row check rejects odd turns. `l_rules.pair_rows_stats` does the row checks without that rule.
3. **Features** (L.11.2), all on select seeds 600–607 and activity seeds 500–507:
   - `G` = for types MBON13 and MBON05, every select seed has X ≥ 5 and Y ≥ 5, where each select seed's pre count is `[x, y]`.
   - `S = k_metrics.pair_metrics(fx, fy, w13, w05)["S"]`, with `w13 = k_metrics.readout_weights(conn, pops, "MBON13", 5)`.
   - `f2 = min(median(x13), median(y13))`.
   - `f3 = |{fx>0} ∩ {fy>0}| / max(|{fx>0} ∪ {fy>0}|, 1)`.
   - Rule directions: S > t, f2 > t, f3 < t.
4. **Even features** come from the pinned ceiling raw file (`fx`, `fy`, `select.pre`), rows with `mode == "x_only"` and `axis == "b"`. **Odd features:**
   - `fx`/`fy` are rebuilt from the pinned K cache. Its `inputs.odours` must equal `KMeasurer`'s de-duplicated odour list for `k_pairs.odd_pairs(pops)` (same order), or the run is refused.
   - `select.pre` comes from stage 0's oracle rows.
5. **Stage-0 self-checks.**
   - (i) The K cache's `inputs.params` equals `params_json(C3)`, and the ceiling file's `params["C3"]` equals `params_json(C3)`. The ceiling file must also have `pairs_digest == SPEC.j.h4.pairs_digest`, `complete`, not `smoke`, and empty `dirty_hashed`.
   - (ii) For every odd pair, the oracle's `kc.x.frac` / `kc.y.frac` / `spikes` per seed equal the values recomputed from the K cache: `len(kc)/n_kc` and `sum(n)`.
   - (iii) The oracle re-run on the first even (b) pair reproduces H.4's recorded stats (`j_rules.pair_mismatch`). This last check is the plan's form of L.2's "stored variant reproduces the H.4 cache row": no variant exists, so the same job is rerun.
   - A mismatch exits 5 (stop, the user decides).
6. **LOTO groups** are the turn numbers: even 0–14 and odd 1–15 are disjoint, giving 16 folds. Within these 16 turns, "my species" is `POOL[turn]`, so the species-grouped fold is the same partition. The record states that fact instead of computing it twice.
7. **Stage-1 selection** (`l_screen.choose`). Candidates are G alone and G ∧ (f op t). Each t is a midpoint between adjacent distinct values of f among the G-passing training pairs. The rule set is filtered to coverage (passes / |train|) ≥ 0.35. The winner is the maximum precision, with ties broken by larger coverage, then family order (G, S, f2, f3), then enumeration order. For f3 (<), candidates are enumerated in descending t, so that "larger coverage first" is well defined. If no rule qualifies, the result is `None`.
8. **Gate outcome order:** `SCREEN_NO_RULE` if the full-41 choice is `None`; else `SCREEN_FEW` if LOTO passes < 10; else `SCREEN_IMPRECISE` if LOTO precision < 0.6; else `SCREEN_GO`. A fold with no rule predicts every held-out pair as fail.
9. **New set** (`l_pairs.new_turns`).
   - Ordered (me, opp) pairs of distinct `POOL` species are enumerated in POOL order (240). The build_turns combos `(POOL[i], POOL[(5i+3)%16])` for i < 16 are removed. The H.5 combos are removed: `(POOL[i], POOL[(7i+5+k)%16])`, with the first k ≥ 0 whose species ≠ `POOL[i]`, for i < 16. The rest is permuted by `default_rng(20260927).permutation`, and the first 64 are taken.
   - Turn j gets `hps[j % 6]` (build_turns' list) and candidates `me.attacks[:4]`.
   - The alternate opponent is `POOL[(pos(opp)+k)%16]`, the first k ≥ 1 with no shared type and ≠ me. If none exists, the generator raises with the turn.
   - (b) pairs come in candidate order. (a) pairs come from `itertools.combinations` within the turn.
   - A pair is **skipped and recorded** if its normalised odour pair equals one from all 16 build_turns turns (both axes, via `k_pairs.odour_key`) or an earlier pair of the new set.
10. **Stage-2 stop.** Pairs are measured in batches of `n_workers`, in declared order. The rule is applied in order, and n* = the order position of the 21st pass. Pairs measured after n* in the last batch are cached but neither screened nor counted: coverage = 21/n*. `COVERAGE_SHORT` holds when position `min(84, len(b))` is reached with fewer than 21 passes.
11. **Naive measurement for screening** is a new job, `l_jobs.naive_job`: `oracle_job`'s first half with the identical call sequence. That is `reset_weights`, plasticity off, activity X then Y on act seeds, weights at w0, then `decide` probes on select seeds. It returns `fx`, `fy` (as sparse index/value lists), `pre` per type and `kc`. A self-check in the stage-2 CLI runs it on the first even (b) pair and requires bit equality with the ceiling raw row. On mismatch it exits 5.
12. **Stage-3 aggregate.** `h4_formula.arm_aggregate` runs over the 21 passing (b) pairs and the fixed first-8-turn (a) pairs, reading in `j_rules.stage2_reading(agg, SPEC.j)` (identical bands). The lift pairs are measured by the same oracle but kept out of the aggregate.
13. **D.6 on C3** (L.11.1) runs `j_runner.measure_d6(jm, ctx, c3)` with `d6a.SEEDS`. It is a record only.
14. **Whole-procedure OC** (L.11.4) is computed after stage 0 and before the stage-1 CLI. It uses the 41 real feature vectors and the real turn structure. Labels are drawn as Bernoulli(q) for G-passing pairs and Bernoulli(q_fail) for the rest, with q_fail ∈ `SPEC.oc_q_fail` = (0.0, 0.1). The gate is run on each draw. P(SELECTED) is taken as P(GO) × (1 − P(COVERAGE_SHORT | c)) × P(stage-3 SELECTED | q), with independence stated. The stage-3 exact table (Poisson-binomial) covers q_b ∈ {LOTO precision (filled at stage 1, recorded then), 0.5, 0.6, 0.7}, naive_a 2–8, q_a/q_b ∈ {0.5, 1}, and u = 0 (C3 turn-effect rows reuse `stage2_oc.turn_effects` / `pair_offsets` on H.4's structure). `numpy.random.default_rng(SPEC.oc_seed)` runs 2000 draws.
15. **Stage-1 OC q_b row.** The LOTO-precision row of the stage-3 table is added by the stage-1 CLI to its own block. The OC block written before stage 1 holds the other rows.
16. **Commit gates.**
    - The stage-2 CLI refuses unless `results/summary/l_screen.json` is git-tracked and unchanged against HEAD, with blocks `stage0`, `oc` and `stage1` present and stage1's outcome `SCREEN_GO`.
    - The stage-3 CLI refuses unless the same file is clean at HEAD with a `stage2` block whose outcome is `SCREENED`.
    - Every stage refuses a previous block whose `measure_key` or `code.key` differs from the current one (manifest check).

## Review Focus

1. **The K cache's odour order drifting from `odd_pairs`.** The same odours in another order would silently attach f vectors to the wrong pair. Expect a refusal with both digests. Test in Task 5.
2. **An odd or new turn with no type-disjoint alternate opponent.** Expect a raise naming the turn, not a silent drop that changes the pair count. Test in Task 2.
3. **Screening where the 21st pass lands mid-batch.** Expect later passes in that batch to be excluded from the 21 and from the coverage denominator. Test in Task 4.
4. **A stage CLI run against a summary edited after its commit, or produced under other code.** Expect refusal before any measurement. Test in Task 7.
5. **A fold whose training pairs have no coverage-qualifying rule.** Expect held-out pairs predicted as fail and the fold recorded as `None`, not an exception or a silently dropped fold. Test in Task 3.

```python
# flymon/brain/l_store.py
"""Guarded writes of spec appendix L: reports under results/m0d/l/ and the summary results/summary/l_screen.json;
nothing else. Caches also live under results/m0d/l/ but go through h3_store. Every write is atomic (tmp + os.replace)."""
from __future__ import annotations

import json
import os
import sys
import uuid
from pathlib import Path

from .h3_store import canonical_pretty
from .pool_bench import refuse_modified_engine_output, refuse_old_engine_output

ALLOWED_DIR = "results/m0d/l/"
SUMMARY = "results/summary/l_screen.json"


def guard(path, params_list) -> None:
    for p in params_list:
        refuse_old_engine_output(str(path), p.kc_kc_scale)
        refuse_modified_engine_output(str(path), p)
    rel = os.path.relpath(os.path.abspath(str(path)), os.getcwd()).replace(os.sep, "/")
    if not (rel.startswith(ALLOWED_DIR) or rel == SUMMARY):
        print(f"refusing to write {path}: spec L writes only under {ALLOWED_DIR} and {SUMMARY}", file=sys.stderr)
        raise SystemExit(2)


def write_bytes(path, data: bytes, params_list) -> Path:
    guard(path, params_list)
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(f".{path.name}.{uuid.uuid4().hex}.tmp")
    tmp.write_bytes(data)
    os.replace(tmp, path)
    return path


def write_json(path, obj, params_list) -> Path:
    return write_bytes(path, (canonical_pretty(obj) + "\n").encode(), params_list)


def write_summary_block(path, block: str, obj, params_list) -> Path:
    guard(path, params_list)
    doc = json.loads(Path(path).read_text()) if Path(path).exists() else {}
    doc[block] = json.loads(canonical_pretty(obj))
    return write_json(path, doc, params_list)
```

```python
# flymon/brain/l_pairs.py
"""The new pair set of spec appendix L (L.4, L.11.3): ordered (my species, opponent) combos of the 16-mon pool that
neither build_turns (turns 0-15) nor H.5's confirmation formula uses, permuted once by default_rng(20260927), the first
64 taken. Turn j: HP from build_turns' 6-cycle at j, candidates = my attacks (at most 4), G.11's type-disjoint alternate
opponent stepping from the opponent's pool position. (b) pairs per candidate; (a) pairs (G.10) only for the first
a_turns turns (F_a's fixed sample). A pair whose normalised odour pair equals one of the 16 old turns (both axes) or an
earlier new pair is skipped and recorded. Independence from the old sets is partial (same species pool, K.8.1)."""
from __future__ import annotations

import itertools

import numpy as np

from ..battle.pool import POOL
from .h4_pairs import build_turns, e0_channels, odour, pool_vocabulary
from .k_pairs import odour_key

HPS = [(0.9, 0.9), (0.9, 0.3), (0.5, 0.6), (0.2, 0.8), (0.6, 0.2), (0.3, 0.5)]   # build_turns' list


def excluded_combos() -> set:
    n = len(POOL)
    out = {(POOL[i].species, POOL[(5 * i + 3) % n].species) for i in range(n)}
    for i in range(n):
        k = 0
        while POOL[(7 * i + 5 + k) % n].species == POOL[i].species:
            k += 1
        out.add((POOL[i].species, POOL[(7 * i + 5 + k) % n].species))
    return out


def new_turns(species_types, move_info, n_turns: int, seed: int) -> list:
    ex = excluded_combos()
    combos = [(a, b) for a in POOL for b in POOL if a.species != b.species and (a.species, b.species) not in ex]
    order = np.random.default_rng(seed).permutation(len(combos))
    turns = []
    for j, ix in enumerate(order[:n_turns]):
        me, opp = combos[int(ix)]
        my_hp, op_hp = HPS[j % len(HPS)]
        cands = [{"move": a, "type": move_info[a][0], "bp": move_info[a][1]} for a in me.attacks][:4]
        turns.append({"turn": j, "pos": j, "me": me.species, "opp": opp.species,
                      "my_types": list(species_types[me.species]), "opp_types": list(species_types[opp.species]),
                      "my_hp": my_hp, "opp_hp": op_hp, "candidates": cands})
    return turns


def alternate_from(opp: str, me: str, opp_types, species_types, turn: int) -> str:
    names = [m.species for m in POOL]
    start = names.index(opp)
    for k in range(1, len(names)):
        cand = names[(start + k) % len(names)]
        if cand != me and not (set(species_types[cand]) & set(opp_types)):
            return cand
    raise ValueError(f"turn {turn}: no type-disjoint alternate opponent")


def _both(p) -> frozenset:
    return frozenset((odour_key(p["odor_x"]), odour_key(p["odor_y"])))


def _turn_pairs(pops, chan, t, species_types, with_a: bool) -> list:
    od = lambda c, opp_types: odour(pops, chan, t["my_types"], opp_types, c["type"], c["bp"], t["my_hp"], t["opp_hp"])
    cands, out = t["candidates"], []
    if with_a:
        for i, j in itertools.combinations(range(len(cands)), 2):
            out.append({"axis": "a", "turn": t["turn"], "x": cands[i]["move"], "y": cands[j]["move"],
                        "odor_x": od(cands[i], t["opp_types"]), "odor_y": od(cands[j], t["opp_types"])})
    alt = alternate_from(t["opp"], t["me"], t["opp_types"], species_types, t["turn"])
    for c in cands:
        out.append({"axis": "b", "turn": t["turn"], "x": f"{c['move']} vs {t['opp']}", "y": f"{c['move']} vs {alt}",
                    "odor_x": od(c, t["opp_types"]), "odor_y": od(c, list(species_types[alt]))})
    return out


def old_pairs(pops, chan, species_types, move_info) -> list:
    """Every (a) and (b) pair of build_turns' 16 turns (even and odd), for the odour-level exclusion."""
    from .h4_pairs import alternate_opponent
    out = []
    for t in build_turns(species_types, move_info, 16):
        od = lambda c, opp_types, t=t: odour(pops, chan, t["my_types"], opp_types, c["type"], c["bp"], t["my_hp"],
                                             t["opp_hp"])
        cands = t["candidates"]
        for i, j in itertools.combinations(range(len(cands)), 2):
            out.append({"odor_x": od(cands[i], t["opp_types"]), "odor_y": od(cands[j], t["opp_types"])})
        alt = alternate_opponent(t["turn"], t["me"], t["opp_types"], species_types)
        out += [{"odor_x": od(c, t["opp_types"]), "odor_y": od(c, list(species_types[alt]))} for c in cands]
    return out


def new_pairs(pops, spec) -> dict:
    species_types, move_info, mon_types, move_types = pool_vocabulary()
    chan = e0_channels(pops, mon_types, move_types)
    seen = {_both(p) for p in old_pairs(pops, chan, species_types, move_info)}
    old = set(seen)
    out = dict(b=[], a=[], skipped=[])
    for t in new_turns(species_types, move_info, spec.n_turns, spec.rng_seed):
        for p in _turn_pairs(pops, chan, t, species_types, with_a=t["turn"] < spec.a_turns):
            k = _both(p)
            if k in seen:
                out["skipped"].append({"key": [p["axis"], p["turn"], p["x"], p["y"]],
                                       "reason": "old_set" if k in old else "in_set"})
                continue
            seen.add(k)
            out[p["axis"]].append(p)
    return out
```

```python
# flymon/brain/l_screen.py
"""Spec L.11.2, stage 1 as pure functions: the naive features of a (b) pair, the candidate rules (G alone, G and one
threshold on S / f2 / f3), the choice under a coverage floor, the leave-one-turn-out gate and its result codes. Nothing
here runs the engine."""
from __future__ import annotations

import numpy as np

from .k_metrics import pair_metrics

SCREEN_GO = "SCREEN_GO"
SCREEN_FEW = "SCREEN_FEW"                 # LOTO passes < gate_min_passes: precision cannot be judged (user decides)
SCREEN_IMPRECISE = "SCREEN_IMPRECISE"     # LOTO precision < gate_min_precision: closes the naive-screen claim
SCREEN_NO_RULE = "SCREEN_NO_RULE"         # no rule meets the coverage floor on all 41 pairs (user decides)


def features(fx, fy, pre: dict, w13, w05, spec) -> dict:
    fx, fy = np.asarray(fx, float), np.asarray(fy, float)
    g = all(min(xy) >= spec.guard_min for t in spec.guard_types for xy in pre[t])
    x13 = [xy[0] for xy in pre["MBON13"]]; y13 = [xy[1] for xy in pre["MBON13"]]
    on_x, on_y = fx > 0, fy > 0
    return dict(G=bool(g), S=float(pair_metrics(fx, fy, w13, w05)["S"]),
                f2=float(min(np.median(x13), np.median(y13))),
                f3=float((on_x & on_y).sum() / max(int((on_x | on_y).sum()), 1)))


def passes(rule, feat: dict) -> bool:
    if rule is None or not feat["G"]:
        return False
    if rule["family"] == "G":
        return True
    v = feat[rule["family"]]
    return v > rule["t"] if rule["op"] == ">" else v < rule["t"]


def rules_for(train: list, spec) -> list:
    out = [{"family": "G"}]
    for fam in spec.family_order[1:]:
        op = dict(spec.directions)[fam]
        vals = sorted({p["feat"][fam] for p in train if p["feat"]["G"]}, reverse=(op == "<"))
        ts = [(a + b) / 2.0 for a, b in zip(vals, vals[1:])]
        out += [{"family": fam, "op": op, "t": float(t)} for t in ts]
    return out


def _score(rule, train):
    hit = [p["testable"] for p in train if passes(rule, p["feat"])]
    return len(hit), sum(hit)


def choose(train: list, spec) -> dict | None:
    best, best_key = None, None
    fam_rank = {f: i for i, f in enumerate(spec.family_order)}
    for i, r in enumerate(rules_for(train, spec)):
        n, k = _score(r, train)
        cov = n / len(train) if train else 0.0
        if n == 0 or cov < spec.cov_min_stage1:
            continue
        key = (k / n, cov, -fam_rank[r["family"]], -i)
        if best_key is None or key > best_key:
            best, best_key = dict(rule=r, precision=k / n, coverage=cov, n_pass=n), key
    return best


def loto(pairs: list, spec) -> dict:
    folds, n_pass, n_hit = [], 0, 0
    for t in sorted({p["turn"] for p in pairs}):
        c = choose([p for p in pairs if p["turn"] != t], spec)
        rule = None if c is None else c["rule"]
        held = [p for p in pairs if p["turn"] == t]
        pred = [passes(rule, p["feat"]) for p in held]
        n_pass += sum(pred); n_hit += sum(pr and p["testable"] for pr, p in zip(pred, held))
        folds.append(dict(turn=t, rule=rule, predicted=pred))
    return dict(folds=folds, n_pass=n_pass, n_hit=n_hit, precision=(n_hit / n_pass) if n_pass else None)


def auc(values, labels, higher_passes: bool) -> float | None:
    """P(a testable pair scores better than a non-testable one), ties 1/2 (Mann-Whitney)."""
    pos = [v for v, l in zip(values, labels) if l]; neg = [v for v, l in zip(values, labels) if not l]
    if not pos or not neg:
        return None
    s = sum((1.0 if (a > b) == higher_passes and a != b else 0.5 if a == b else 0.0) for a in pos for b in neg)
    return s / (len(pos) * len(neg))


def gate(pairs: list, spec) -> dict:
    final = choose(pairs, spec)
    lo = loto(pairs, spec)
    if final is None:
        outcome = SCREEN_NO_RULE
    elif lo["n_pass"] < spec.gate_min_passes:
        outcome = SCREEN_FEW
    elif lo["precision"] < spec.gate_min_precision:
        outcome = SCREEN_IMPRECISE
    else:
        outcome = SCREEN_GO
    lab = [p["testable"] for p in pairs]
    rec = dict(auc={f: auc([p["feat"][f] for p in pairs], lab, dict(spec.directions)[f] == ">")
                    for f in spec.family_order[1:]},
               by_set={s: _by_set(pairs, final, s) for s in ("even", "odd")},
               loto_rule_counts=_rule_counts(lo["folds"]),
               species_folds="identical to the turn folds: turn i's species is POOL[i] for i < 16 (plan reading 6)")
    return dict(outcome=outcome, final=final, loto=lo, records=rec)


def _by_set(pairs, final, s):
    sub = [p for p in pairs if p["set"] == s]
    rule = None if final is None else final["rule"]
    pas = [p for p in sub if passes(rule, p["feat"])]
    pos = [p for p in sub if p["testable"]]
```

```python
def pair_rows_stats(rows: list, z: dict, expected: list, spec4) -> dict:
    reasons = []
    keys = [_key(r) for r in rows]
    if len(set(keys)) != len(keys):
        reasons.append("duplicate pair rows")
    exp = {tuple(k) for k in expected}
    if set(keys) != exp:
        reasons.append(f"pairs differ from the declared list (missing {len(exp - set(keys))}, "
                       f"extra {len(set(keys) - exp)})")
    n = len(spec4.report_seeds)
    short = {_key(r) for r in rows if any(len(r["report"][ph][k]) != n for ph in ("pre", "R1", "R2") for k in "AP")}
    if short:
        reasons.append(f"{len(short)} pairs whose report probes are not the {n} report seeds")
    stats = {_key(r): pair_stats(r["report"], z, spec4.testable_min) for r in rows if _key(r) not in short}
    if any(s is None for s in stats.values()):
        reasons.append(f"{sum(s is None for s in stats.values())} pairs with an undefined d'")
    if any(s is not None and any(np.isnan(s[f]) for f in ("d_pre", "r", "p", "m")) for s in stats.values()):
        reasons.append("pairs with a NaN statistic")
    return dict(reasons=reasons, stats=stats,
                pairs=[dict(axis=k[0], turn=k[1], x=k[2], y=k[3], **(s or {})) for k, s in stats.items()])


def screen_order(feats: list, rule, n_pass: int, max_screened: int) -> dict:
    passed, screened = [], []
    for i, f in enumerate(feats[:max_screened]):
        screened.append(i)
        if passes(rule, f):
            passed.append(i)
            if len(passed) == n_pass:
                return dict(outcome=SCREENED, passed=passed, n_star=i + 1, screened=screened,
                            coverage=n_pass / (i + 1))
    return dict(outcome=COVERAGE_SHORT, passed=passed, n_star=None, screened=screened,
                coverage=len(passed) / len(screened) if screened else 0.0)


def lift_draw(failed_idx: list, n: int, seed: int) -> list:
    if len(failed_idx) <= n:
        return list(failed_idx)
    pick = np.random.default_rng(seed).choice(len(failed_idx), size=n, replace=False)
    return [failed_idx[int(i)] for i in pick]
```

```python
# flymon/brain/l_jobs.py
"""The FlyPool job of spec appendix L's screening (L.11.3): the naive half of h4_jobs.oracle_job with the identical
call sequence — weights reset, plasticity off, X's then Y's KC activity on the act seeds, weights at w0, the
two-odour decision probes on the select seeds — so a screened pair's features equal the ones the oracle would compute.
Signature fn(engine, plasticity, pops, comps, readout, **kwargs), module-level for the spawn pool."""
from __future__ import annotations

import numpy as np

from .h4_jobs import _present_kc, rig_for, type_cells
from .presentation import decide


def naive_job(eng, pl, pops, comps, ro, params, odor_x: dict, odor_y: dict, types, act_seeds, select_seeds,
              strength: float, settle_ms: float, read_ms: float, window_ms: int) -> dict:
    e, p, c = rig_for(eng.conn, pops, params)
    cells = type_cells(e.conn, types)
    idx = np.concatenate([cells[n] for n in types])
    bounds = np.cumsum([0] + [len(cells[n]) for n in types])
    try:
        p.reset_weights(); p.set_enabled(False)

        def activity(odor):
            fired = np.zeros(len(pops.kc)); frac, spikes, max_win = [], [], []
            for s in act_seeds:
                o = _present_kc(e, p, pops, odor, int(s), strength, settle_ms, read_ms, window_ms)
                fired += o["read"] > 0; frac.append(float((o["read"] > 0).mean())); spikes.append(int(o["read"].sum()))
                max_win.append(o["max_win"])
            return fired / len(act_seeds), {"frac": frac, "spikes": spikes, "max_win": max_win}

        fx, kc_x = activity(odor_x)
        fy, kc_y = activity(odor_y)
        e.csc.w[p.edges] = p.w0
        pre = {n: [] for n in types}
        for s in select_seeds:
            cnt = decide(e, p, pops, [odor_x, odor_y], strength, int(s), settle_ms, read_ms, idx=idx)
            for j, n in enumerate(types):
                pre[n].append(cnt[:, bounds[j]:bounds[j + 1]].sum(1).tolist())
        nzx, nzy = np.flatnonzero(fx), np.flatnonzero(fy)
        return {"fx_idx": nzx.tolist(), "fx_val": fx[nzx].tolist(), "fy_idx": nzy.tolist(), "fy_val": fy[nzy].tolist(),
                "pre": pre, "kc": {"x": kc_x, "y": kc_y,
                                   "jaccard": float(((fx > 0) & (fy > 0)).sum() / max(((fx > 0) | (fy > 0)).sum(), 1))}}
    finally:
        p.reset_weights(); p.set_enabled(True)
```

```python
def check_pinned(path, sha: str) -> dict:
    got = sha256_file(path)
    if got != sha:
        raise ValueError(f"{path}: sha256 {got[:12]} is not the pinned {sha[:12]}")
    return json.loads(Path(path).read_text())


def dense(idx, val, n: int) -> np.ndarray:
    v = np.zeros(int(n)); v[np.asarray(idx, np.int64)] = np.asarray(val, float)
    return v


def load_even(spec, c3_json: dict) -> list:
    """The 21 even (b) pairs' fx, fy and select-seed probes from H.4a.8's raw file (mode x_only), in H.4 order."""
    d = check_pinned(spec.ceiling_path, spec.ceiling_sha256)
    if d.get("pairs_digest") != spec.j.h4.pairs_digest or not d.get("complete") or d.get("smoke") or d.get("dirty_hashed"):
        raise ValueError("ceiling raw file is not the complete, clean run on the declared pairs")
    if d["params"]["C3"] != c3_json:
        raise ValueError("ceiling raw file's C3 engine is not the recorded C3 engine")
    rows = [r for r in d["rows"]["C3"] if r["mode"] == "x_only" and r["axis"] == "b"]
    return [dict(key=("b", int(r["turn"]), r["x"], r["y"]), fx=np.asarray(r["fx"], float), fy=np.asarray(r["fy"], float),
                 pre=r["select"]["pre"]) for r in rows]


def load_odd_activity(spec, odd: list, n_kc: int, c3_json: dict, seeds=None) -> list:
    """The odd pairs' fx / fy from K's C3 activity cache, refused unless its odours are KMeasurer's list for `odd`."""
    d = check_pinned(spec.k_act_path, spec.k_act_sha256)
    if d["inputs"]["params"] != c3_json:
        raise ValueError("K activity cache is not the recorded C3 engine")
    km = KMeasurer(None, None, odd, n_kc, None)
    if [odour_key(o) for o in d["inputs"]["odours"]] != [odour_key(o) for o in km.odours]:
        raise ValueError("K activity cache's odour order differs from odd_pairs' de-duplicated odours")
    seeds = [int(s) for s in (seeds if seeds is not None else spec.j.h4.act_seeds)]
    if [int(s) for s in d["inputs"]["seeds"]] != seeds:
        raise ValueError("K activity cache was measured on other act seeds")
    fired = np.zeros((len(km.odours), int(n_kc)))
    for r in d["result"]:
        fired[r["i"], r["kc"]] += 1
    fired /= len(seeds)
    return [dict(fx=fired[ix], fy=fired[iy]) for ix, iy in km.index]


class _Missing(Exception):
    pass


def _missing(*_):
    raise _Missing                      # h4_measure's pattern: a cache probe that never computes


class LMeasurer:
    def __init__(self, pool, spec, types, cache):
        self.pool, self.spec, self.types, self.cache = pool, spec, tuple(types), cache
        self.params_seen: list = []

    def naive(self, params, pairs: list) -> list:
        """naive_job per pair, cached per pair, run in rounds of one pair per worker (an interruption loses a round)."""
        if params not in self.params_seen:
            self.params_seen.append(params)
        h4 = self.spec.j.h4
        common = dict(params=params, types=self.types, act_seeds=tuple(h4.act_seeds), select_seeds=tuple(h4.select_seeds),
                      strength=h4.h3.strength, settle_ms=h4.oracle_window.settle_ms, read_ms=h4.oracle_window.read_ms,
                      window_ms=int(h4.kc_window_ms))
        items = [dict(common, odor_x=p["odor_x"], odor_y=p["odor_y"]) for p in pairs]
        inputs = lambda i: dict(items[i], pair=[pairs[i]["axis"], int(pairs[i]["turn"]), pairs[i]["x"], pairs[i]["y"]])
        done = {}
        for i in range(len(items)):
            try:
                done[i] = self.cache.get_or_compute("l_naive", inputs(i), _missing, [params])
            except _Missing:
                pass
        todo = [i for i in range(len(items)) if i not in done]
        n = max(1, self.pool.n_workers)
        for r in range(0, len(todo), n):
            batch = todo[r:r + n]
            for i, out in zip(batch, self.pool.run_jobs(l_jobs.naive_job, [items[i] for i in batch])):
                done[i] = self.cache.get_or_compute("l_naive", inputs(i), lambda out=out: out, [params])
        return [done[i] for i in range(len(items))]
```

```python
# flymon/brain/l_oc.py
"""Spec L.11.4: operating characteristics of the whole L procedure, recorded before stage 1 (never changes a judgement).
Stage 1's gate is simulated on the 41 real feature vectors and turn structure with Bernoulli labels (q for G-passing
pairs, q_fail otherwise); stage 2's COVERAGE_SHORT is the binomial tail (21st pass after position 84 <=> fewer than 21
passes in 84); stage 3 is J.12.9's exact Poisson-binomial table on 21 (b) pairs and the fixed (a) sample, read by the
judgement's own function. The product assumes the three stages independent (stated in the record)."""
from __future__ import annotations

from math import comb

import numpy as np

from .j_rules import B_FA, B_NO_CONCLUSION, B_TB, SELECTED
from .l_rules import stage3_reading
from .l_screen import SCREEN_FEW, SCREEN_GO, SCREEN_IMPRECISE, SCREEN_NO_RULE, gate

BANDS = (SELECTED, B_TB, B_NO_CONCLUSION, B_FA)


def coverage_short_prob(c: float, n_pass: int, max_screened: int) -> float:
    return float(sum(comb(max_screened, k) * c ** k * (1 - c) ** (max_screened - k) for k in range(n_pass)))


def _pb(probs) -> np.ndarray:
    dist = np.array([1.0])
    for p in probs:
        dist = np.convolve(dist, [1.0 - p, p])
    return dist


def stage3_table(q_bs, naive_as, ratios, spec, u_offsets=None) -> list:
    """u_offsets: None (u = 0: pairs independent) or 21 logit offsets for the (b) pairs (C3's turn effects)."""
    n_b = spec.j.stage2_n_b
    rows = []
    for q_b in q_bs:
        pb = _pb([q_b] * n_b if u_offsets is None else [1 / (1 + np.exp(-(np.log(q_b / (1 - q_b)) + o)))
                                                        for o in u_offsets])
        for na in naive_as:
            for ratio in ratios:
                q_a = q_b * ratio
                pa = _pb([q_a] * na)
                P = {b: 0.0 for b in BANDS}
                for tb, w_b in enumerate(pb):
                    for fa, w_a in enumerate(pa):
                        rd = stage3_reading(dict(testable_b=tb, n_b=n_b, T_b=tb / n_b, F_a=fa, naive_a=na), spec)
                        P[rd["band"]] += w_b * w_a
                rows.append(dict(q_b=q_b, q_a=q_a, naive_a=na, u="C3" if u_offsets is not None else 0, P=P))
    return rows


def gate_oc(pairs: list, q: float, q_fail: float, spec, rng, draws: int | None = None) -> dict:
    n = draws or spec.oc_draws
    out = {k: 0 for k in (SCREEN_GO, SCREEN_FEW, SCREEN_IMPRECISE, SCREEN_NO_RULE)}
    for _ in range(n):
        lab = [bool(rng.random() < (q if p["feat"]["G"] else q_fail)) for p in pairs]
        out[gate([dict(p, testable=l) for p, l in zip(pairs, lab)], spec)["outcome"]] += 1
    return {k: v / n for k, v in out.items()}


def whole(gate_p: float, short_p: float, sel_p: float) -> float:
    return float(gate_p * (1.0 - short_p) * sel_p)
```
