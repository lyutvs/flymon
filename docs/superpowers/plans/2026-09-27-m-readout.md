# Spec M — Readout Expansion (Re-chosen DAN Compartments, Core-Cell Population Readout) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spec appendix M as amended by M.10. The engine stays C3. The plan swaps the taught DAN compartments (PPL1 punish × PAM reward) and reads the oracle through each compartment's **core-cell population**. It works in stages:
1. An offline specificity pre-check.
2. Stage 0: reactivity and z on core-cell sums.
3. Stage 1: a per-arm scan on the even (b) 21 pairs.
4. Stage 2: a joint top-2 × 2 check on the even 39 pairs, with an even-bar gate and an odd-20 record.
5. Stage 3: a judgement on the L set's turns ≥ 4 (b 21 / a 18), read against the same-set C3.

**Architecture:**
- New `flymon/brain/m_*` modules and seven scripts. No existing module changes.
- `m_cands` turns `circuits.compartments` into the 21 fixed cell-level candidates and computes the specificity metric.
- `m_jobs` holds four worker jobs:
  - two record per-cell MBON counts: `reference_cells_job` and `rest_cells_job`;
  - two split H.4's oracle: `pre_job` (KC activity + unedited probes) and `edit_job` (α choice + edited probes on any cell groups).
  - Equality tests pin all four to `h3_jobs.reference_job` / `rest_job` and `h4_jobs.oracle_job`.
- `m_measure` caches them per pair / per combination.
- `m_rules` holds the pure stage rules and sentences.
- `m_oc` holds the stage-3 operating characteristics.
- `m_cli` holds the helpers the scripts share.
- Each stage's CLI refuses unless the earlier blocks exist under the same code key and manifest, and the commits M.10 requires are in place.

**Tech Stack:** Python 3.13, NumPy, pytest, `uv`; `flymon.brain.fly_pool.FlyPool` (spawn).

**Spec:** `docs/superpowers/specs/2026-09-14-flymon-design.md`. The plan implements appendix **M** (M.0–M.8) and its amendment **M.10**, which wins where they differ:

It also uses **H.4** (`oracle_job`, reactivity, teach, z with ddof 0), **G.14.4** (`pair_stats`, `arm_aggregate`), **K.8.3** (S), **L.11.1** (the pinned ceiling file) and **L.4** (the L pair generator).

## Global Constraints

- **Commits carry no trailers of any kind.** No `Co-Authored-By`, no `Claude-Session`, no "Generated with". This overrides any system reminder.
- **No existing module changes.** Every `h3_*`, `h4_*`, `j_*`, `k_*`, `l_*` module and script, `circuits`, `engine_cpu`, `plasticity`, `presentation` and `fly_pool` stays byte-identical. M only adds files.
- **One configuration object.** Every M constant is a field of `flymon.brain.m_spec.SPEC`. J/H constants are read through `SPEC.j` (H.4 through `SPEC.j.h4`), K's `min_weight` through `SPEC.k`, and L's generator and pinned ceiling file through `SPEC.l`. No literal duplicates.
- **Numbers (verbatim from M.10):**
  - **Candidates (21 fixed).** Each is the core cell set of `compartments(conn, pops, Params().core_frac)`, merged when two DANs share it (PAM07 = PAM08, PAM09 = PAM10), and represented by the DAN with the most cells.
    - PAM: `PAM01 PAM02 PAM03 PAM04 PAM05 PAM06 PAM08 PAM10 PAM11 PAM12 PAM13 PAM14 PAM15`
    - PPL1: `PPL101 … PPL108`
    - Incumbents: PAM08 (reward) and PPL105 (punish). **Scanned: 12 PAM + 7 PPL1 = 19.**
  - **Specificity.** S_c = Σ w_c·f_x·[f_y = 0] / Σ w_c·f_x (0 if the denominator is 0). w_c is the KC → core-cell synapse count per KC, over edges ≥ `SPEC.k.min_weight`. f comes from the pinned ceiling file (even (b) 21 pairs, act seeds 500–507).
    - The candidate value is the median over the 21 pairs.
    - A candidate passes iff its median is **strictly greater** than its arm incumbent's median.
    - `STOP_NO_SPECIFICITY` iff no candidate passes in either arm. An arm with none is fixed to its incumbent.
  - **Reactivity** follows H.4: median(read − same-seed rest) ≥ 5 ∧ zero share ≤ 0.25 over H.3's reference set of 96 presentations, applied to the core-cell sum. z = (mean, population sd), valid only when finite and sd > 0.
  - **Stages 1–2.** The oracle uses H.4's seeds and α grid (act 500–507, select 600–607, report 608–615, α ∈ {0.2, 0.5, 0.8}); `testable_min` = 2.0.
    - The per-arm top **2** go on.
    - The stage-2 winner is chosen **bar-first**: testable_b ≥ 11 ∧ F_a ≥ 2 first, then testable_b, then F_a, then median m.
    - Gate: the winner meets the bar on the even 21 (b) + 18 (a).
    - The odd (b) 20 are recorded for the winner.
  - **Judgement set.** `l_pairs.new_pairs` with `a_turns = 64`. The first **21** (b) pairs with turn ≥ **4**, plus every (a) pair of those turns. Turns 4, 5, 7–12 give **b 21 / a 18**, with pinned digests:
    - b `f55be2dfd868ab7ec1ab2913a2d1cbf3ba6823f1ca4b307fe42392149461d162`
    - a `a978f054fb497d23ca620354b8b92e2c4871ad17770fbec990b10a0828350dc1`
  - **Reading.** n = selected testable_b / 21, c = same-set C3 testable_b / 21.
    - `SELECTED` ⇔ n ≥ 11 ∧ F_a ≥ 2 ∧ n > c
    - `B_Fa` ⇔ n ≥ 11 ∧ F_a < 2 ∧ n > c
    - `B_Tb` ⇔ n ≤ c
    - otherwise `B_NO_CONCLUSION`
    - No reading unless n_b = 21.
  - **OC.** u = 0 exact; q_b ∈ {0.33, 0.5, 0.6, 0.7}; q_a/q_b ∈ {0.5, 1}; naive_a 0–8; c ∈ {2, 4, 7}.
- **Pinned inputs:**
  - `SPEC.l.ceiling_path` / `ceiling_sha256` (L.11.1), loaded through `l_measure.load_even`.
  - `results/summary/m0d.json`, used for C3's `Params` (block `h3`) and for block `h4`'s C3 readout {A: MBON13, P: MBON05}, reactivity, z (ddof 0) and pools.
  - `SPEC.k.odd_pairs_digest` for the odd 20.
- **Every output path is guarded.** Caches go under `results/m0d/m/` through `h3_store`. Reports go under `results/m0d/m/` and the summary is `results/summary/m_readout.json`, both through `m_store`. Anything else is refused.

## Readings of the spec (decided here)

1. **Candidate construction.** For each family (`Compartment.family` is "PAM" or "PPL1"), DAN types with a non-empty `core` are grouped by the sorted tuple of core indices.
   - The representative is the DAN with the most `cells`; ties go to the first name in sorted order.
   - The recorded `dans` list names every member.
   - `m_cands.candidates` refuses (`ValueError`) unless the representatives equal `SPEC.reward_candidates` / `SPEC.punish_candidates` in order.
   - The cell digest is `sha256(json.dumps(sorted(cells)))`.
2. **Overlap.** Two groups overlap iff their cell sets intersect.
   - A scanned candidate whose cells overlap the fixed-arm incumbent of the other arm is skipped in that arm and recorded. None do today.
   - A stage-2 combination whose two groups overlap is excluded and recorded.
3. **Specificity weights.** `m_cands.cell_weights(conn, pops, cells, min_weight)` is `k_metrics.readout_weights` with `np.isin(conn.post, cells)` in place of the type mask. A test pins them equal when the cells are all of one type.
   - Lobe shares use `k_metrics.lobe_masks`: `w[mask].sum() / w.sum()`.
   - The incumbents' values are computed the same way on their core cells. PPL105's core is MBON13 + MBON18 cells; PAM08's is MBON05 + MBON21.
4. **Per-cell counts.** `reference_cells_job` / `rest_cells_job` repeat `h3_jobs.reference_job` / `rest_job`'s presentation sequence exactly: `engine_for`, reset, clear_drive, present, settle, then read_steps steps. They return the read counts of the listed cells, which are `pops.mbon`.
   - A group's value is the sum over its cells.
   - Stage 0's self-check: the type sums for MBON13 / MBON05 reproduce block `h4`'s C3 reactivity (every field) and z **exactly**. A mismatch exits 5.
5. **The oracle split.**
   - `pre_job` = `oracle_job` up to and including the unedited probes. That is: reset weights, plasticity off, activity X then Y on the act seeds, weights at w0, `decide` on the select seeds, and `decide` on the report seeds. Probes record the per-cell counts of the listed cells (`pops.mbon`).
   - `edit_job` takes `pre_job`'s fx and the unedited per-cell probes, the groups (name → cell list, each ⊂ cells), the readout {A, P} (group names), z, and the reward / punish DAN names.
   - `edit_job` then runs `oracle_job`'s α choice and edited probes: select R1 per α, then R2 per α, then report R1 and R2. The edits touch the named DANs' `core` KC→MBON edges.
   - `m_measure.compose(pre, edit, groups)` returns the row in `oracle_job`'s shape, with counts per group.
   - Test: `compose` with groups = type cells equals `oracle_job` on the synthetic connectome (dict equality).
6. **Readouts.** A candidate group's readout is its own core-cell sum.
   - The incumbent **population** readouts are "PPL105" (A) and "PAM08" (P), both core-cell sums. Stages 1–2 use them for the fixed arm.
   - C3's **single** readout (types MBON13 / MBON05, block `h4` z) is used only for stage 0's self-check and stage 3's same-set baseline. Stage 3 uses `h4_measure.H4Measurer.oracle` unchanged for that baseline.
7. **Incumbent population guard.** If either incumbent population fails reactivity or has an invalid z, stage 0 ends `STOP_INCUMBENT` (exit 5, the user decides). M.10 assumes they pass.
8. **Stage-0 candidates.** Only candidates that passed specificity are measured for reactivity and teach. `STOP_NO_CANDIDATE` iff, after the guard, both arms are empty. An arm left empty is fixed to its incumbent.
9. **Teach record.** `h4_jobs.teach_job` runs unchanged per passing candidate with its core **types**:
   - PAM candidates: arm `reward_only`, `reward_type` = candidate, `punish_type` = PPL105.
   - PPL1 candidates: arm `punish_only`, `punish_type` = candidate, `reward_type` = PAM08.
   - Both orders × `teach_seeds`. Each core type is recorded through `h4_rules.teach_choice(rows, t, arm, SPEC.j.h4)`. A record, not a gate.
10. **Stage-1 arm rows.**
    - Reward-arm candidate c: `reward_type` = c, `punish_type` = PPL105, readout {A: "PPL105", P: c}, z from stage 0.
    - Punish-arm candidate c: `reward_type` = PAM08, `punish_type` = c, readout {A: c, P: "PAM08"}.
    - Each arm also measures the incumbent itself (reward PAM08 / punish PPL105, population readouts) as a **reference row**, which is not ranked.
    - n_r = #pairs with `pair_stats(...)["r"] ≥ 2`; n_p = #pairs with `−p ≥ 2`. An undefined stat counts as not passing.
    - Rank by (−n, −median(r or −p over defined pairs), −Σ w_c).
    - Top 2, or all if fewer. An arm with no scanned candidates uses [incumbent].
11. **Predicted joint counts** (record). For each reward-arm row i and punish-arm row j, including the reference rows: #pairs with r_i ≥ 2 ∧ −p_j ≥ 2 on the same pair.
12. **Stage-2 combinations.** top_r × top_p minus overlapping ones. Joint oracle on even `h4_pairs.even_pairs(pops)` ((a) 18 + (b) 21) with readout {A: punish group, P: reward group}, then `arm_aggregate` with H.4's thresholds.
    - Winner: bar-first order (Global Constraints).
    - Gate `STAGE2_GO` iff the winner meets the bar; else `STOP_NO_GAIN`.
    - The winner is also run on `k_pairs.odd_pairs(pops)` (20 (b)), and its testable count is recorded whatever the gate says.
13. **Judgement list** (`m_rules.judgement_set`) is pure over `l_pairs.new_pairs(pops, replace(SPEC.l, a_turns=SPEC.l.n_turns))`. It refuses (`ValueError`) unless both digests equal the pinned ones. A spec with empty digests is smoke only and never writes a block. The list CLI writes block `list` with the keys and digests.
14. **n ≥ 11 with c ≥ n.** M.10.5 lists both "B_Tb ⇔ n ≤ c" and "B_결론없음 ⇔ … n ≥ 11 but c ≥ n". Those overlap exactly when c ≥ n ≥ 11. This plan applies B_Tb first (n ≤ c), so an overlapping case reads **B_Tb**, carrying the note "C3 자체가 기준을 넘어…" whenever c ≥ 11. The B_결론없음 clause is left with c < n < 11.
15. **Stage 3.** The selected combination through `MMeasurer`, and C3 through `H4Measurer` (types = block `h4` pools), both on the judgement list. `arm_aggregate` gives n, F_a and naive_a; C3's gives c. Then `m_rules.stage3_reading`.
16. **Commit gates**, each using `l_cli.check_committed`:

    | CLI | Requires |
    |---|---|
    | stage0 | `spec_check` committed and outcome `SPEC_GO` |
    | oc | `stage0` present |
    | stage1 | `spec_check`, `stage0`, `oc` committed |
    | stage2 | `stage1` present |
    | list | `stage2` committed and outcome `STAGE2_GO` |
    | stage3 | `stage2` and `list` committed |

    - Every CLI refuses blocks produced under other code (`same_code`) and an upstream run-id mismatch (`run_id_chain`).
    - It refuses to rewrite a block when a later one exists (`later_blocks` over `m_cli.ORDER`).
    - Stages 1–3 refuse a `results/summary/m0d.json` whose sha256 differs from block `stage0`'s (`l_cli.stage0_inputs`).
17. **Smoke.** `m_spec.smoke(SPEC)`:
    - 2 reward candidates (PAM08, PAM10) and 2 punish candidates (PPL105, PPL103);
    - 2 even (b) pairs and 2 even (a) pairs;
    - odd 2;
    - judgement from turn 13, n_b 2, with empty judgement digests (so no block and no reading).

    Smoke never touches the judgement set (turns 4–12). The controller hand-edits smoke gates when needed (Runs).

## Review Focus

1. **A candidate whose core is only part of its type (PAM13: 5 of 13 cells).** Expect the readout sum, the edited edges and the specificity weights to use exactly those 5 cells, not the type. Test in Tasks 2, 3 and 4.
2. **`compose(pre_job, edit_job)` drifting from `oracle_job`.** Any call-order change would silently change the labels. Expect dict equality on the synthetic connectome for the incumbent type readout. Test in Task 3.
3. **A group whose reference sum has sd = 0 or is non-finite.** Expect "z invalid" and a guard fail, not a division by zero inside `dv`. Test in Task 4.
4. **Stage-3 reading at the edges.** n = c ≥ 11 must not be SELECTED. n = c + 1 = 11 with F_a = 2 is SELECTED. n_b ≠ 21 gives no reading. Test in Task 5.
5. **A CLI run on a summary edited after its commit, on another m0d.json, or on blocks from other code.** Expect refusal before any pool starts. Test in Tasks 7–9.

# flymon/brain/m_spec.py
"""The configuration of spec appendix M as amended by M.10: C3 unchanged; the taught DAN compartments re-chosen among
21 cell-level core candidates (PAM reward x PPL1 punish, 19 scanned), read through their core-cell population; an
offline specificity pre-check, a per-arm scan and a joint top-2 x 2 check on even pairs, and a judgement on the L set's
turns >= 4 against the same-set C3. `j` carries every J/H constant, `k` K's min_weight, `l` L's pair generator and the
pinned ceiling file. Nothing here repeats one of them."""
from __future__ import annotations

import dataclasses
from dataclasses import dataclass

from .j_spec import SPEC as J_SPEC, JSpec
from .k_spec import SPEC as K_SPEC, KSpec
from .l_spec import SPEC as L_SPEC, LSpec


@dataclass(frozen=True)
class MSpec:
    j: JSpec = J_SPEC
    k: KSpec = K_SPEC
    l: LSpec = L_SPEC
    m0d_path: str = "results/summary/m0d.json"
    readout_c3: tuple = (("A", "MBON13"), ("P", "MBON05"))     # block h4's C3 single readout (reading 6)
    # ---- candidates (M.10.1): representatives of the distinct core cell sets ----------------------------------------
    reward_family: str = "PAM"
    punish_family: str = "PPL1"
    reward_candidates: tuple = ("PAM01", "PAM02", "PAM03", "PAM04", "PAM05", "PAM06", "PAM08", "PAM10", "PAM11",
                                "PAM12", "PAM13", "PAM14", "PAM15")   # PAM07 = PAM08, PAM09 = PAM10 (same core cells)
    punish_candidates: tuple = ("PPL101", "PPL102", "PPL103", "PPL104", "PPL105", "PPL106", "PPL107", "PPL108")
    incumbent_reward: str = "PAM08"
    incumbent_punish: str = "PPL105"
    # ---- stages 1-2 (M.3, M.10.3) ------------------------------------------------------------------------------------
    top_k: int = 2
    # ---- judgement set (M.10.4) --------------------------------------------------------------------------------------
    judge_from_turn: int = 4
    judge_n_b: int = 21
    judge_n_a: int = 18
    judge_b_digest: str = "f55be2dfd868ab7ec1ab2913a2d1cbf3ba6823f1ca4b307fe42392149461d162"
    judge_a_digest: str = "a978f054fb497d23ca620354b8b92e2c4871ad17770fbec990b10a0828350dc1"
    # ---- smoke sizes (reading 17) -------------------------------------------------------------------------------------
    n_even_b: int | None = None           # None = all declared even (b) pairs; smoke uses 2
    n_even_a: int | None = None
    n_odd: int | None = None
    # ---- operating characteristics (M.10.6) -------------------------------------------------------------------------
    oc_q_b: tuple = (0.33, 0.5, 0.6, 0.7)
    oc_ratio: tuple = (0.5, 1.0)
    oc_naive_a: tuple = tuple(range(0, 9))
    oc_c: tuple = (2, 4, 7)
    attempts: tuple = (("I", "M2 no-go", "dc9d8b2"), ("J", "STD B_Tb 4/21", "0917b1a"),
                       ("K", "fast KC-KC inhibition B_Tb 4/21", "73bfc2a"),
                       ("L", "naive-readout screen SCREEN_IMPRECISE 7/15", "c3d2e25"), ("M", "this declaration", "1441eba"))

    def dict_readout_c3(self) -> dict:
        return dict(self.readout_c3)

```python
# flymon/brain/m_cands.py
"""Spec M.10.1-M.10.2: the candidates are the distinct CORE CELL sets of the PAM (reward) and PPL1 (punish) DAN types
(circuits.compartments' core: MBON cells with w_mbon >= core_frac) — two DANs with the same cells are one candidate,
named by the DAN with most cells; the offline specificity metric S_c is K.8.3's S with the KC weights onto the
candidate's core cells; a candidate goes on only when its median S over the even (b) 21 pairs is strictly above its arm
incumbent's."""
from __future__ import annotations

import hashlib
import json

import numpy as np

from .k_metrics import _kc_pos, pair_metrics

SPEC_GO = "SPEC_GO"
STOP_NO_SPECIFICITY = "STOP_NO_SPECIFICITY"


def cells_digest(cells) -> str:
    return hashlib.sha256(json.dumps(sorted(int(i) for i in cells)).encode()).hexdigest()


def core_groups(cell_types, comps: dict, family: str) -> list:
    """One entry per distinct non-empty core cell set of `family`'s DAN types, sorted by representative name."""
    t = np.asarray(cell_types).astype(str)
    by: dict = {}
    for name in sorted(comps):
        cp = comps[name]
        if cp.family != family or len(cp.core) == 0:
            continue
        by.setdefault(tuple(sorted(int(i) for i in cp.core)), []).append(name)
    out = []
    for cells, names in by.items():
        rep = max(names, key=lambda n: (len(comps[n].cells), -names.index(n)))    # most cells, then first name
        out.append(dict(name=rep, dans=list(names), family=family, cells=list(cells),
                        types=sorted(set(t[list(cells)].tolist())), n_dan_cells=int(len(comps[rep].cells)),
                        digest=cells_digest(cells), w_mbon=[float(comps[rep].w_mbon[i]) for i in cells]))
    return sorted(out, key=lambda d: d["name"])


def candidates(cell_types, comps: dict, spec) -> dict:
    """{"reward": PAM groups, "punish": PPL1 groups}; ValueError unless the representatives are the declared lists."""
    out = {"reward": core_groups(cell_types, comps, spec.reward_family),
           "punish": core_groups(cell_types, comps, spec.punish_family)}
    for arm, want in (("reward", spec.reward_candidates), ("punish", spec.punish_candidates)):
        got = tuple(c["name"] for c in out[arm])
        if got != tuple(want):
            raise ValueError(f"{arm} candidates {got} are not the declared {tuple(want)} ({spec.reward_family} / "
                             f"{spec.punish_family} core cell sets, M.10.1)")
    return out


def overlap(a: dict, b: dict) -> bool:
    return bool(set(a["cells"]) & set(b["cells"]))


def cell_weights(conn, pops, cells, min_weight: int) -> np.ndarray:
    """k_metrics.readout_weights on a cell list: per-KC synapse count onto `cells` over edges >= min_weight."""
    pos = _kc_pos(conn, pops)
    sel = (pos[conn.pre] >= 0) & np.isin(conn.post, np.asarray(cells, np.int64)) & (conn.w >= min_weight)
    return np.bincount(pos[conn.pre[sel]], weights=conn.w[sel].astype(np.float64), minlength=len(pops.kc))


def lobe_shares(w, lobes: dict) -> dict:
    tot = float(np.sum(w))
    return {k: (float(np.sum(w[m])) / tot if tot > 0 else 0.0) for k, m in lobes.items()}


def pair_s(fx, fy, w) -> float:
    return pair_metrics(fx, fy, w, w)["S"]


def spec_check(values: dict, spec) -> dict:
    """values: {candidate name: [S per even (b) pair]} for every declared candidate (incumbents included). A candidate
    passes iff its median is strictly above its arm incumbent's; STOP_NO_SPECIFICITY iff none passes in either arm."""
    med = {k: float(np.median(v)) for k, v in values.items()}
    q = {k: [float(x) for x in np.percentile(v, [25, 75])] for k, v in values.items()}
    inc = {"reward": med[spec.incumbent_reward], "punish": med[spec.incumbent_punish]}
    arms = {"reward": (spec.reward_candidates, spec.incumbent_reward),
            "punish": (spec.punish_candidates, spec.incumbent_punish)}
    passing = {a: [n for n in names if n != i and med[n] > inc[a]] for a, (names, i) in arms.items()}
    outcome = SPEC_GO if passing["reward"] or passing["punish"] else STOP_NO_SPECIFICITY
    return dict(outcome=outcome, medians=med, quartiles=q, incumbent_median=inc, passing=passing)

"""FlyPool worker jobs of spec appendix M (M.10.1, readings 4-5). reference_cells_job / rest_cells_job are
h3_jobs.reference_job / rest_job's presentation sequence with the read counts of a cell list (every MBON cell) instead
of type sums; pre_job is h4_jobs.oracle_job up to its unedited probes (KC activity of X then Y on the act seeds, then
decide() on the select and on the report seeds, at w0, plasticity off) with per-cell counts; edit_job is the rest of
oracle_job — the reward alpha on the select seeds, the punishment alpha given it, then R1 and R2 on the report seeds —
with the readout V built from named cell groups. Composed on type-cell groups they are oracle_job (test). Signature
fn(engine, plasticity, pops, comps, readout, **kwargs), module-level so the spawn pool can pickle them."""

import numpy as np

from .h3_jobs import engine_for
from .h4_formula import dprime, dv
from .h4_jobs import _present_kc, rig_for
from .presentation import decide
from .stimuli import present


def group_counts(counts, cells, groups: dict) -> dict:
    """counts: [seed][2][len(cells)] -> {group: [[x, y] per seed]} (sums over the group's cells)."""
    pos = {int(c): k for k, c in enumerate(cells)}
    ix = {g: [pos[int(i)] for i in idx] for g, idx in groups.items()}
    arr = np.asarray(counts, np.int64)
    return {g: arr[:, :, k].sum(axis=2).tolist() for g, k in ix.items()}


def reference_cells_job(eng, pl, pops, comps, ro, params, odors, strength: float, settle_ms: float, read_steps: int,
                        cells) -> list:
    e, _ = engine_for(eng.conn, pops, params)
    idx = np.asarray(cells, np.int64)
    out = []
    for o in odors:
        for seed in o["seeds"]:
            e.reset(int(seed)); e.clear_drive(); present(e, pops, o["strengths"], strength); e.run(settle_ms)
            counts = np.zeros(e.N, np.int32)
            for _ in range(read_steps):
                counts[e.step()] += 1
            out.append(dict(odor=o["name"], seed=int(seed), counts=counts[idx].tolist()))
    return out


def rest_cells_job(eng, pl, pops, comps, ro, params, seeds, settle_ms: float, read_steps: int, cells) -> list:
    e, _ = engine_for(eng.conn, pops, params)
    idx = np.asarray(cells, np.int64)
    out = []
    for seed in seeds:
        e.reset(int(seed)); e.clear_drive(); e.run(settle_ms)
        counts = np.zeros(e.N, np.int32)
        for _ in range(read_steps):
            counts[e.step()] += 1
        out.append(dict(seed=int(seed), counts=counts[idx].tolist()))
    return out

def pre_job(eng, pl, pops, comps, ro, params, odor_x: dict, odor_y: dict, cells, act_seeds, select_seeds, report_seeds,
            strength: float, settle_ms: float, read_ms: float, window_ms: int) -> dict:
    e, p, c = rig_for(eng.conn, pops, params)
    idx = np.asarray(cells, np.int64)
    try:
        p.reset_weights(); p.set_enabled(False)

        def activity(odor):
            fired = np.zeros(len(pops.kc)); frac, spikes, max_win = [], [], []
            for s in act_seeds:
                o = _present_kc(e, p, pops, odor, int(s), strength, settle_ms, read_ms, window_ms)
                fired += o["read"] > 0; frac.append(float((o["read"] > 0).mean())); spikes.append(int(o["read"].sum()))
                max_win.append(o["max_win"])
            return fired / len(act_seeds), {"frac": frac, "spikes": spikes, "max_win": max_win}

        fx, kc_x = activity(odor_x)
        fy, kc_y = activity(odor_y)
        e.csc.w[p.edges] = p.w0
        pre_sel = _probe(e, p, pops, odor_x, odor_y, select_seeds, strength, settle_ms, read_ms, idx)
        pre_rep = _probe(e, p, pops, odor_x, odor_y, report_seeds, strength, settle_ms, read_ms, idx)
        nx, ny = np.flatnonzero(fx), np.flatnonzero(fy)
        return {"fx_idx": nx.tolist(), "fx_val": fx[nx].tolist(), "fy_idx": ny.tolist(), "fy_val": fy[ny].tolist(),
                "pre_sel": pre_sel, "pre_rep": pre_rep,
                "kc": {"x": kc_x, "y": kc_y,
                       "jaccard": float(((fx > 0) & (fy > 0)).sum() / max(((fx > 0) | (fy > 0)).sum(), 1))}}
    finally:
        p.reset_weights(); p.set_enabled(True)


def edit_job(eng, pl, pops, comps, ro, params, odor_x: dict, odor_y: dict, fx_idx, fx_val, cells, groups: dict,
             readout: dict, z: dict, pre_sel, select_seeds, report_seeds, alphas, strength: float, settle_ms: float,
             read_ms: float, reward_type: str, punish_type: str) -> dict:
    e, p, c = rig_for(eng.conn, pops, params)
    idx = np.asarray(cells, np.int64)
    fx = np.zeros(len(pops.kc)); fx[np.asarray(fx_idx, np.int64)] = np.asarray(fx_val, float)

    def ap(counts):
        g = group_counts(counts, cells, {"A": groups[readout["A"]], "P": groups[readout["P"]]})
        return {"A": g["A"], "P": g["P"]}

    try:
        p.reset_weights(); p.set_enabled(False)
        rew = np.isin(p.post_mb, p.mb_local[c[reward_type].core]); pun = np.isin(p.post_mb, p.mb_local[c[punish_type].core])
        w = e.csc.w

        def set_w(a_r, a_p=None):
            wv = p.w0.copy()
            if a_r is not None:
                wv[rew] = p.w0[rew] * (1.0 - a_r * fx)[p.pre_kc[rew]]
            if a_p is not None:
                wv[pun] = p.w0[pun] * (1.0 - a_p * fx)[p.pre_kc[pun]]
            w[p.edges] = wv

        probe = lambda seeds: _probe(e, p, pops, odor_x, odor_y, seeds, strength, settle_ms, read_ms, idx)
        reward = {}
        for a in alphas:
            set_w(a); r1 = probe(select_seeds)
            reward[str(a)] = {"R": r1, "change": dprime(dv(ap(r1), z) - dv(ap(pre_sel), z))}
        a_r = max(alphas, key=lambda a: (reward[str(a)]["change"], -a))
        punish = {}
        for a in alphas:
            set_w(a_r, a); r2 = probe(select_seeds)
            punish[str(a)] = {"R": r2, "change": dprime(dv(ap(r2), z) - dv(ap(reward[str(a_r)]["R"]), z))}
        a_p = min(alphas, key=lambda a: (punish[str(a)]["change"], a))
        set_w(a_r); R1 = probe(report_seeds)
        set_w(a_r, a_p); R2 = probe(report_seeds)
        w[p.edges] = p.w0
        return {"reward": reward, "punish": punish, "alpha_reward": a_r, "alpha_punish": a_p, "R1_rep": R1, "R2_rep": R2,
                "readout": dict(readout)}
    finally:
        p.reset_weights(); p.set_enabled(True)
```

"""The pure rules of spec appendix M (M.10.3-M.10.5): per-arm counts (n_r = pairs with r >= testable_min, n_p = pairs
with -p >= testable_min; an undefined pair counts as not passing), ranking (n, then the median of r or -p over the
defined pairs, then the core's KC input), top-k, the predicted joint counts (record), overlap-free combinations, the
bar-first choice (testable_b >= 11 and F_a >= 2 first), the judgement list (L set turns >= 4, first 21 (b) + those
turns' (a), digests pinned), and the reading against the same-set C3 (SELECTED needs n > c, B_Tb is n <= c)."""
from __future__ import annotations

import numpy as np

from .h4_formula import pair_stats
from .h4_pairs import pairs_digest
from .m_cands import overlap

STAGE2_GO = "STAGE2_GO"
STOP_NO_GAIN = "STOP_NO_GAIN"
STOP_NO_CANDIDATE = "STOP_NO_CANDIDATE"
STOP_INCUMBENT = "STOP_INCUMBENT"
SELECTED, B_TB, B_FA, B_NO_CONCLUSION = "SELECTED", "B_Tb", "B_Fa", "B_NO_CONCLUSION"


def arm_rows(reports: list, z: dict, arm: str, h4spec) -> dict:
    """reports: the rows' report dicts ({pre, R1, R2} of {A, P}) in pair order."""
    st = [pair_stats(rep, z, h4spec.testable_min) if rep is not None else None for rep in reports]
    r = [s["r"] if s else None for s in st]
    p = [s["p"] if s else None for s in st]
    val = r if arm == "reward" else [(-x if x is not None else None) for x in p]
    ok = [v for v in val if v is not None]
    return dict(n=int(sum(1 for v in ok if v >= h4spec.testable_min)), med=float(np.median(ok)) if ok else float("-inf"),
                r=r, p=p, defined=len(ok))


def rank(entries: list, arm: str) -> list:
    return sorted(entries, key=lambda e: (-e["n"], -e["med"], -e["kc_input"]))


def top(ranked: list, k: int) -> list:
    return ranked[:k]


def predicted_joint(reward_r: dict, punish_p: dict, tmin: float) -> dict:
    out = {}
    for i, r in reward_r.items():
        for j, p in punish_p.items():
            out[f"{i}|{j}"] = int(sum(1 for a, b in zip(r, p) if a is not None and b is not None and a >= tmin
                                      and -b >= tmin))
    return out


def combos(top_r: list, top_p: list) -> tuple:
    ok, bad = [], []
    for a in top_r:
        for b in top_p:
            (bad.append([a["name"], b["name"]]) if overlap(a, b) else ok.append((a, b)))
    return ok, bad


def meets_bar(agg: dict, jspec) -> bool:
    return bool(agg["testable_b"] >= jspec.stage2_select_testable_b and agg["F_a"] >= jspec.h4.f_a_min)


def choose(aggs: dict, jspec) -> list:
    """[(name, agg)] best first: bar met, then testable_b, F_a, median m."""
    return sorted(aggs.items(), key=lambda kv: (not meets_bar(kv[1], jspec), -kv[1]["testable_b"], -kv[1]["F_a"],
                                                 -kv[1].get("m_median", 0.0)))


def judgement_set(new_all: dict, spec) -> dict:
    """new_all: l_pairs.new_pairs with a_turns = n_turns. The first judge_n_b (b) pairs with turn >= judge_from_turn and
    every (a) pair of their turns; ValueError unless both digests are the pinned ones (an empty pin = smoke)."""
    b = [p for p in new_all["b"] if int(p["turn"]) >= spec.judge_from_turn][:spec.judge_n_b]
    turns = {int(p["turn"]) for p in b}
    a = [p for p in new_all["a"] if int(p["turn"]) in turns]
    bd, ad = pairs_digest(b), pairs_digest(a)
    if spec.judge_b_digest and (bd != spec.judge_b_digest or ad != spec.judge_a_digest):
        raise ValueError(f"judgement list digest (b {bd[:12]}, a {ad[:12]}) is not the pinned "
                         f"(b {spec.judge_b_digest[:12]}, a {spec.judge_a_digest[:12]}) — M.10.4")
    return dict(b=b, a=a, b_digest=bd, a_digest=ad)


def stage3_reading(agg: dict, agg_c3: dict, spec) -> dict:
    """M.10.5: SELECTED iff n >= 11 and F_a >= 2 and n > c; B_Fa iff n >= 11, F_a < 2, n > c; B_Tb iff n <= c; else
    B_NO_CONCLUSION. No reading unless n_b is the declared 21."""
    j = spec.j
    n, c, fa, n_b = int(agg["testable_b"]), int(agg_c3["testable_b"]), int(agg["F_a"]), int(agg["n_b"])
    base = dict(n=n, c=c, F_a=fa, n_b=n_b, naive_a=int(agg["naive_a"]),
                f_a_possible=bool(agg["naive_a"] >= j.h4.f_a_min))
    if n_b != spec.judge_n_b or int(agg_c3["n_b"]) != spec.judge_n_b:
        return dict(base, outcome=None, note="pair list is not the declared 21: not a judgement")
    if n <= c:
        out = B_TB
    elif n >= j.stage2_select_testable_b:
        out = SELECTED if fa >= j.h4.f_a_min else B_FA
    else:
        out = B_NO_CONCLUSION
    note = "C3 자체가 기준을 넘어 판독 확장의 효과로 말할 수 없다" if c >= j.stage2_select_testable_b else None
    return dict(base, outcome=out, note=note)

# flymon/brain/m_oc.py
"""Spec M.10.6: the stage-3 operating characteristics, recorded before stage 1 and never changing a judgement. u = 0
(the pairs independent — the new judgement set's turn effects are unknown before it is measured): testable_b ~
Poisson-binomial(21 x q_b), F_a ~ Poisson-binomial(naive_a x q_a) with q_a = ratio x q_b, the same-set C3 count c fixed
at each declared value; every (n, F_a) cell is read by m_rules.stage3_reading itself."""
from __future__ import annotations

from .l_oc import stage2_oc
from .m_rules import B_FA, B_NO_CONCLUSION, B_TB, SELECTED, stage3_reading

OUTCOMES = (SELECTED, B_TB, B_NO_CONCLUSION, B_FA)
ASSUMPTION = ("u = 0: pairs independent with testable probability q_b ((b)) and q_a = ratio x q_b ((a)); the same-set C3 "
              "count c fixed; each cell read by m_rules.stage3_reading. A record, not a judgement.")


def stage3_table(spec) -> list:
    pb_fn = stage2_oc().poisson_binomial
    n_b = spec.judge_n_b
    rows = []
    for q_b in spec.oc_q_b:
        pb = pb_fn([q_b] * n_b)
        for ratio in spec.oc_ratio:
            q_a = ratio * q_b
            for naive_a in spec.oc_naive_a:
                pa = pb_fn([q_a] * naive_a) if naive_a else [1.0]
                for c in spec.oc_c:
                    P = {o: 0.0 for o in OUTCOMES}
                    for n, p_n in enumerate(pb):
                        for fa, p_f in enumerate(pa):
                            agg = dict(testable_b=n, F_a=fa, n_b=n_b, naive_a=naive_a)
                            out = stage3_reading(agg, dict(testable_b=c, F_a=0, n_b=n_b, naive_a=0), spec)["outcome"]
                            P[out] += float(p_n) * float(p_f)
                    rows.append(dict(q_b=q_b, ratio=ratio, q_a=q_a, naive_a=naive_a, c=c, P=P))
    return rows

def out_allowed(out) -> bool:
    rel = os.path.relpath(os.path.abspath(str(out)), ROOT).replace(os.sep, "/")
    return (rel + "/").startswith(m_store.ALLOWED_DIR)


def git_state(files=HASHED_FILES) -> dict:
    return h3_store.git_state(files=files)


def code_keys(npz) -> tuple:
    missing = [f for f in HASHED_FILES if not (ROOT / f).exists()]
    if missing:
        refuse(f"the hashed files {missing} do not exist (the manifest covers every M module and script)")
        raise SystemExit(2)
    return code_key(npz, files=MEASURE_FILES), code_key(npz, files=HASHED_FILES)


def read_previous(summary, need, smoke: bool, committed) -> tuple:
    """(doc, None) or (None, refusal): outside --smoke the summary is git-tracked and clean at HEAD (`committed`); then
    every block of `need` present. --smoke reads only a summary under results/m0d/m/."""
    if smoke:
        if not out_allowed(summary):
            return None, f"a --smoke run reads and writes only a smoke summary under {m_store.ALLOWED_DIR}, not {summary}"
    elif need:
        why = committed(summary, list(need))
        if why:
            return None, why
    try:
        doc = json.loads(Path(summary).read_text()) if need or Path(summary).exists() else {}
    except (OSError, ValueError) as e:
        return None, f"no usable summary at {summary}: {e}"
    missing = [b for b in need if not isinstance(doc.get(b) if isinstance(doc, dict) else None, dict)]
    if missing:
        return None, f"{summary} lacks the blocks {missing} (each earlier stage's block comes first)"
    return doc, None


def later_blocks(summary, name: str, doc: dict | None = None) -> str | None:
    if doc is None:
        try:
            doc = json.loads(Path(summary).read_text())
        except OSError:
            return None
        except ValueError as e:
            return f"no usable summary at {summary}: {e}"
    later = [b for b in ORDER[ORDER.index(name) + 1:] if isinstance(doc, dict) and b in doc]
    return None if not later else (f"{summary} already holds the later blocks {later}: block {name} is not rewritten "
                                   f"under them (start a new summary, or --smoke)")

    return m_store.write_summary_block(summary, name, dict(res, report=str(report), report_sha256=sha256_file(report)),
