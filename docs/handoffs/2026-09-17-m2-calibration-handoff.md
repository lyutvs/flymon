## 3. 이번 세션에서 확정·기록된 것

### D.6 (STD 재검토 조건) 현재 상태
- **(a) 미충족 — 여유 0**: 최대 서브창 KC 발화율이 임계와 같은 150.0 Hz, 격자 타일·8시드로 잼. **이동 창·64시드 재판정(G.8)은 아직 안 돌렸다.**
- **(b) 충족 — 발동**(16턴 중 t0·t6·t8, 최대 비율 2.50). 대응은 (c)와 함께 판정하기로 "사후 프로토콜 개정"으로 기록(E.3).
- **(c) 미측정.**
- "STD는 구동량 차이를 안 고친다"는 주장은 **철회**했다(STD는 활동 의존 억압이라 구동 분산을 압축한다; Frontiers 2021).

### 학습 단위 시험 설계 이력 — F v1·v2·v3 모두 철회
- 레드팀 3라운드 × 외부 모델 2개(`gpt-5.6-sol`, `gpt-6-astra`), 전부 RETHINK. 기록 `results/m2/red-team/`.
- v1: 2-후보 턴 7쌍만 보고 "순진 d′ ≈ 0 반증" → 34쌍 전수에는 d′ ≈ 0 쌍이 있었다(표본 선택 인공물).
- v2: 판정 상태기계가 기존 M0c 데이터에서 깨짐(작동하는 프로토콜을 멈춤, noplast가 UNDEFINED, 포화가 FAIL을 숨김).
- v3: 판정 코드를 먼저 검증(35/35)했지만 **보정 안 됨** — 참 d′ = 1인 뇌가 P(FAIL) 0.648·P(PASS) 0.002. 코드 버그(NaN 중앙값 → PASS,
  마리 1마리·빈 noplast도 PASS, 게이트별 중앙값이라 동시 충족 0/8도 PASS) 재현.

## 5. 지켜야 할 사전 등록 규율

- **홀수 턴(1, 3, …, 15)은 한 번도 쓰지 않았다** — F v4 게이트 후보 풀이다(G.2). 짝수 턴은 파일럿·선택 전용.
- **부록 G의 어떤 데이터로도 D.6 (c)를 판정하지 않는다**(G.1).
- 순서: **선언 커밋 → 코드 스모크(1–2 job) → 전체 실행**. 스모크에서 설계 결함이 보이면 전체 실행 전에 개정을 기록한다(G.4a 선례 — 개정은 판정을 관대하게만 만드는 방향일 때 정당화가 쉽다).
- 인코더가 E0에서 바뀌면 **D.6 (b)와 F의 z 상수를 새 인코더에서 다시 잰다**(G.11).
- 사람이 읽는 산문보다 **판정·선택 코드를 먼저** 쓰고 검증한다. 픽스처는 극단값만이 아니라 **문턱 근처·±∞ 혼합·결측·마리별 동시 충족**까지.

## 6. 운영 주의

- **긴 실행**: 백그라운드 Bash는 약 60분에서 끊길 수 있다 → `nohup bash -c "...; echo \$? > X.done" & disown`으로 분리하고 `Monitor`(최대 30분, 만료마다 재무장)로 감시.
  **재부팅은 아무것도 못 넘는다**(2026-09-17 00:10 재부팅으로 첫 인코더 비교가 끊김) → 스크립트를 **단위별 재개 가능**하게(같은 코드 해시일 때만 재사용, 임시 파일 + rename).
- **FlyPool**: 16워커 ≈ 9 GB. `run_jobs`는 맵 전체에 `timeout_s`가 걸린다(기본 3600 s) → 큰 작업은 나눠 호출. 이번 세션 실측: 오라클 35 job 3358 s,
  인코더 비교 인코더당 870–1236 s(39 job). 스크래치에서 FlyPool을 만들면 `if __name__ == "__main__"` 필수.
- **스크립트가 cwd(저장소 루트)에 파일을 쓰지 않게** 한다(이번 세션 `0.35_stage.json` 사고).
- **레드팀**(`plan-red-team`): 외부 모델 두 개를 병렬로 — `PLAN_RED_TEAM_MODEL=gpt-6-astra` 오버라이드, 실행 디렉터리 분리. `gpt-5.6-sol`은 437줄 검토본에서
  max effort로 10분 시간 초과(DEGRADED) → `PLAN_RED_TEAM_EFFORT=high` 또는 검토본을 부록과 필수 배경만으로. 검토본에서 내 자기비판은 뺀다.
  리뷰의 수치·코드 주장은 **원자료로 직접 재현한 뒤** 받아들인다(이번 세션 대부분 맞았지만, 확인 스크립트 쪽 실수도 두 번 있었다).
- 재부팅 직후엔 Spotlight 재색인으로 부하가 높다(로드 19.5) — 처리량 측정은 피한다.
